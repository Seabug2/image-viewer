# Image Viewer

Windows용 단일 실행 파일 이미지 뷰어입니다. 여러 이미지 모음을 1·2·3·4·6개 영역에서 동시에 열고 독립적인 슬라이드쇼로 감상할 수 있습니다. 배포본은 아이콘과 .NET 런타임, SkiaSharp 네이티브 구성요소까지 `ImageViewer.exe` 하나에 포함합니다.

## 주요 기능

- 1·2·3·4·6분할 레이아웃
- 이미지 파일, 폴더, ZIP/CBZ 드래그 앤 드롭
- 여러 폴더·ZIP/CBZ 또는 여러 이미지 동시 드롭 시 대상 영역부터 `1·2·3·4·6` 순서로 최대 5개 자동 배정
- 이미지 파일 하나를 열면 같은 폴더의 지원 이미지 전체를 불러오고 선택한 이미지부터 표시
- JPG, JPEG, PNG, BMP, GIF, TIFF, WebP 지원
- GIF와 애니메이션 WebP 프레임 재생
- 영역별 독립 슬라이드쇼와 0~60초 간격 조절
- 한 주기 안에서 중복되지 않는 무작위 재생
- 현재 이미지 위치 슬라이더와 이전·다음 버튼
- 분할 영역 폭에 맞춰 슬라이더와 보조 표시가 자동 조절되는 반응형 하단 UI
- 숨겨진 분할 영역의 슬라이드쇼와 애니메이션 자동 일시정지
- 각 영역 우측 상단에 마우스를 가져가면 나타나는 `×` 버튼으로 해당 영역 불러오기 종료
- 이전·다음 버튼 우클릭으로 같은 상위 경로의 다른 ZIP/CBZ 또는 폴더 이동
- 우클릭으로 모든 영역의 시간 또는 무작위 설정 동기화
- 일반 창 최대화와 현재 모니터를 채우는 테두리 없는 전체화면

현재 폴더 바로 아래의 이미지만 읽고 하위 폴더는 탐색하지 않습니다.

## 단일 EXE 빌드

```powershell
dotnet publish .\ImageViewer.csproj -c Release -r win-x64 --self-contained true -o .\publish
```
