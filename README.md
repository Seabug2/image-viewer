# Multi Viewer (Image Viewer)

여러 이미지 모음을 한 창의 여러 영역에서 동시에 감상할 수 있는 Windows용 이미지 뷰어입니다. 폴더와 ZIP/CBZ를 압축 해제하지 않고 열 수 있으며, 각 영역마다 독립적인 슬라이드쇼를 실행할 수 있습니다.

배포본은 앱 아이콘, .NET 런타임, SkiaSharp 구성요소를 모두 포함한 `ImageViewer.exe` 단일 파일입니다. 별도의 설치나 추가 DLL이 필요하지 않습니다.

## 다운로드

### [최신 버전 ImageViewer.exe 바로 받기](https://github.com/Seabug2/image-viewer/releases/latest/download/ImageViewer.exe)

- [최신 릴리스 설명과 파일 보기](https://github.com/Seabug2/image-viewer/releases/latest)
- 현재 문서 기준 버전: **v1.4.0**
- 대상 환경: Windows x64

> Windows가 인터넷에서 받은 실행 파일에 SmartScreen 경고를 표시할 수 있습니다. GitHub 릴리스의 파일 정보와 SHA-256 digest를 확인한 뒤 실행하세요.

## 주요 기능

- `1 / 2 / 3 / 4 / 6 / 8`분할 레이아웃
- 이미지·폴더·ZIP·CBZ 드래그 앤 드롭
- JPG, JPEG, PNG, BMP, GIF, TIFF, WebP 지원
- GIF와 애니메이션 WebP 재생
- 영역별 독립 슬라이드쇼와 `0~60초` 간격 설정
- 한 주기 동안 중복되지 않는 무작위 재생
- 이미지 위치 슬라이더, 이전·다음 버튼, 마우스 휠 탐색
- 현재 이미지를 확대하고 강하게 흐린 배경으로 빈 공간 채우기
- 손상되었거나 실제 형식이 맞지 않는 이미지 자동 제외
- 창 크기에 반응하는 하단 조작 UI
- 일반 최대화와 현재 모니터만 채우는 테두리 없는 전체화면
- 실행 파일 하나만 배포하는 self-contained single-file 구성

## 분할 화면

| 버튼 | 배치 |
|---|---|
| `1` | 한 영역 |
| `2` | 좌우 2등분 |
| `3` | 좌우 방향 3등분 |
| `4` | 2×2 |
| `6` | 3×2 |
| `8` | 4×2 |

분할 수를 줄이면 화면에서 사라진 영역의 목록과 현재 위치는 보존됩니다. 숨겨진 영역은 슬라이드쇼 타이머와 GIF/WebP 애니메이션을 정지하므로 CPU·메모리 대역폭을 계속 소비하지 않습니다. 분할 수를 다시 늘리면 해당 영역이 표시될 때 이미지를 다시 준비하고 재생을 재개합니다.

## 불러오기 규칙

### 이미지 파일 하나

이미지 파일 하나를 열거나 드롭하면 그 이미지가 있는 폴더의 지원 이미지 전체를 자연 정렬된 목록으로 구성합니다. 처음 화면에는 사용자가 선택한 이미지가 표시됩니다.

### 폴더 하나

선택한 폴더 바로 아래에 있는 이미지만 읽습니다. 그 폴더 안의 하위 폴더와 하위 압축파일은 자동으로 탐색하지 않습니다.

### ZIP/CBZ 하나

압축을 미리 풀지 않고 내부 이미지 항목을 자연 정렬하여 읽습니다. 큰 압축파일도 목록만 먼저 구성하고 현재 표시할 이미지를 필요할 때 디코딩합니다.

### 여러 항목 동시 드롭

여러 이미지·폴더·ZIP·CBZ를 한 번에 드롭하면 드롭한 영역부터 8번 영역까지 하나씩 순서대로 배정합니다.

예를 들어 2분할 상태에서 2번 영역에 세 항목을 드롭하면 2·3·4번 영역에 배정됩니다. 3·4번 영역은 현재 보이지 않더라도 상태가 저장되며, 나중에 분할 수를 늘리면 확인할 수 있습니다. 8번 영역을 넘어가는 항목은 불러오지 않습니다.

## 이미지 탐색 조작

| 조작 | 동작 |
|---|---|
| 이전·다음 버튼 좌클릭 | 해당 영역의 이전·다음 이미지 |
| 영역에서 휠 위/아래 | 해당 영역의 이전·다음 이미지 |
| `Ctrl` + 이전·다음 버튼 좌클릭 | 현재 표시 중인 모든 영역을 함께 이동 |
| 이전·다음 버튼 우클릭 | 같은 상위 경로의 이전·다음 폴더 또는 ZIP/CBZ로 이동 |
| 이미지 위치 슬라이더 | 목록의 원하는 위치로 바로 이동 |
| 우측 상단 `×` | 해당 영역의 목록을 닫고 기본 화면으로 초기화 |

`Ctrl+좌클릭` 동기 이동은 현재 표시된 영역에만 적용됩니다. 숨겨져 일시정지된 영역과 이미지가 없는 영역은 건드리지 않습니다.

폴더·압축파일 우클릭 순회는 현재 항목과 같은 상위 폴더를 기준으로 합니다. ZIP/CBZ를 파일명 순서로 순회한 뒤 폴더를 파일명 순서로 순회하며, 순회 대상 폴더 내부의 하위 폴더나 압축파일은 탐색하지 않습니다. 이미지가 없는 대상은 안내를 표시하면서 자동으로 건너뜁니다.

## 슬라이드쇼 규칙

- 시간 값이 `0`이면 해당 영역의 슬라이드쇼가 꺼집니다.
- 마지막 이미지 다음에는 첫 이미지로 돌아가 계속 순회합니다.
- 무작위 재생은 한 주기의 모든 이미지를 한 번씩 보여줄 때까지 중복하지 않습니다.
- 한 주기를 모두 소비하면 새로운 무작위 순서를 만들어 다시 시작합니다.
- 위치 슬라이더로 직접 선택한 이미지는 즉시 표시되며, 현재 무작위 주기에서는 다시 나오지 않도록 제외됩니다.
- 손상되어 열 수 없는 이미지는 현재 목록에서 제거되므로 같은 실행 중 다시 선택되지 않습니다.
- 새 전경 이미지와 흐린 배경의 렌더링이 끝난 뒤부터 설정 시간을 새로 계산합니다. 처리가 늦으면 전환 간격이 늘어나며 검은 미완성 배경을 표시한 채 다음 이미지로 넘어가지 않습니다.
- 버튼·휠·위치 슬라이더·`Ctrl+좌클릭`으로 이미지를 수동 변경하면 새 이미지가 완성된 시점부터 시간을 다시 계산합니다.

시간 슬라이더나 숫자 버튼을 우클릭하여 조작하면 현재 값을 모든 영역에 적용합니다. 무작위 토글도 우클릭하면 모든 영역에 같은 설정을 적용합니다.

## 화면과 UI

- 상단 중앙의 분할·전체화면 조작부는 마우스를 가까이 가져갈 때 나타납니다.
- 각 영역의 파일명, 위치·시간 슬라이더와 버튼도 마우스가 가까워질 때 나타납니다.
- 하단 UI는 영역 폭이 좁아지면 슬라이더를 우선 축소하고 보조 문구를 숨겨 잘림을 줄입니다.
- 흐린 배경은 전경과 같은 디코딩 결과를 공유하여 이미지를 두 번 읽지 않습니다.
- GIF·애니메이션 WebP는 흐린 배경을 첫 프레임으로 고정하여 다중 분할 재생 부하를 줄입니다.
- 테두리 없는 전체화면은 창이 위치한 현재 모니터 하나만 채웁니다.

## 손상 파일 처리

확장자가 이미지처럼 보여도 실제 데이터가 손상되었거나 압축 항목 헤더가 깨져 있으면 실제 디코딩 시점에만 오류를 알 수 있습니다. Multi Viewer는 이런 항목 하나 때문에 슬라이드쇼를 멈추지 않습니다.

실패한 항목만 현재 영역의 목록에서 제거하고 다음 정상 이미지로 진행합니다. 순차 재생, 무작위 재생, 마우스 휠, 이전·다음 버튼에 모두 같은 규칙이 적용됩니다. 모든 항목을 열 수 없는 경우에만 빈 화면과 안내 문구를 표시합니다.

## 소스에서 빌드

.NET 10 SDK가 필요합니다.

```powershell
dotnet publish .\ImageViewer.csproj -c Release -r win-x64 --self-contained true -o .\publish
```

빌드 설정은 앱 아이콘과 네이티브 구성요소를 포함한 단일 `ImageViewer.exe`를 생성합니다.
