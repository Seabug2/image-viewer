# Image Viewer

![Image Viewer 아이콘](Assets/ImageViewer.png)

Windows용 단일 실행 파일 이미지 뷰어입니다. 여러 이미지 모음을 1·2·3·4·6개 영역에서 동시에 열고 독립적인 슬라이드쇼로 감상할 수 있습니다. 배포본은 아이콘과 .NET 런타임, SkiaSharp 네이티브 구성요소까지 `ImageViewer.exe` 하나에 포함하므로 설치나 보조 파일이 필요하지 않습니다.

## 주요 기능

- 1·2·3·4·6분할 레이아웃
  - 3분할: 3열 × 1행
  - 6분할: 3열 × 2행
- 이미지 파일, 폴더, ZIP/CBZ 드래그 앤 드롭
- JPG, JPEG, PNG, BMP, GIF, TIFF, WebP 지원
- GIF와 애니메이션 WebP 프레임 재생
- 영역별 독립 슬라이드쇼와 0~60초 간격 조절
- 한 주기 안에서 중복되지 않는 무작위 재생
- 현재 이미지 위치 슬라이더와 이전·다음 버튼
- 이전·다음 버튼 우클릭으로 같은 상위 경로의 다른 ZIP/CBZ 또는 폴더 이동
- 지원 이미지가 없는 공간 자동 건너뛰기
- 우클릭으로 모든 영역의 시간 또는 무작위 설정 동기화
- 일반 창 최대화와 현재 모니터 한 대를 채우는 테두리 없는 전체화면
- 화면 크기에 맞춘 이미지 다운샘플링과 현재 압축 항목만 읽는 메모리 최적화

## 사용법

1. 각 영역에 이미지·폴더·ZIP/CBZ를 끌어 놓거나 **이미지 열기**를 누릅니다.
2. 창 위쪽에 마우스를 가져가 `1 / 2 / 3 / 4 / 6` 레이아웃을 선택합니다.
3. 영역 아래쪽에 마우스를 가져가 이미지 위치와 슬라이드쇼 시간을 조절합니다.
4. 시간 값 `0`은 슬라이드쇼 정지입니다.
5. 시간 증감 버튼이나 시간 슬라이더를 우클릭으로 조작하면 모든 영역이 같은 시간으로 동기화됩니다.
6. **무작위**를 우클릭하면 모든 영역의 무작위 설정이 동기화됩니다.
7. 이미지 이전·다음 버튼을 우클릭하면 같은 상위 경로의 이전·다음 이미지 공간으로 이동합니다.

공간 순서는 ZIP/CBZ 파일명순 다음 폴더명순이며 마지막 폴더 뒤에는 첫 ZIP/CBZ로 순환합니다. 현재 폴더 바로 아래의 이미지만 읽고 하위 폴더나 폴더 내부 압축파일은 탐색하지 않습니다. 지원되는 이미지가 없는 공간은 안내 후 자동으로 건너뜁니다.

## 단일 EXE 빌드

Windows 10/11 x64와 .NET 10 SDK가 필요합니다.

```powershell
dotnet publish .\ImageViewer.csproj -c Release -r win-x64 --self-contained true -o .\publish
```

게시 결과인 `publish\ImageViewer.exe`만 배포하면 됩니다. `Assets` 폴더와 ICO/PNG 파일은 소스 및 빌드용이며 실행 파일 옆에 복사할 필요가 없습니다.

## 아이콘

아이콘은 여러 분할 영역에서 하나의 풍경 이미지를 감상한다는 앱의 핵심 기능을 표현합니다. 원본 PNG와 Windows 다중 해상도 ICO는 `Assets`에 있으며, 빌드 시 ICO가 EXE 리소스와 WPF 창 리소스에 내장됩니다.
